THE IDEA

Why does an agent need a gate?

An agent can propose a useful action without being trusted to authorize it. The gate binds review to an input hash, claims the approved action atomically, and records what happened.

01

Bounded proposal

prepare() persists the actor, action, input hash, and idempotency key.

02

Separate review

approve() belongs behind a host-owned, authenticated review surface.

03

Uncertain result

execute() never assumes a network error means the provider did nothing.
